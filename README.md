## 🧑‍🏫 02 · AI Teaching Assistant

### RAG-Based Learning Assistant for Educational Videos

An AI Teaching Assistant that allows users to ask questions about **uploaded educational videos and YouTube content**.

The system processes video content, converts speech into text, creates embeddings, retrieves relevant context, and generates answers using a local LLM.

### ✨ Key Features

* 🎥 Upload educational videos
* ▶️ YouTube learning support
* 🎙️ Speech-to-text using Whisper
* 🧠 Retrieval-Augmented Generation
* 🔎 Semantic similarity search
* 📚 Embedding-based retrieval
* 🤖 Ollama-powered local LLM
* ⏱️ Timestamp-based source references

### 🧰 Tech Stack

`Python` `Flask` `Whisper` `RAG` `Ollama` `NumPy` `Pandas` `Scikit-Learn`
